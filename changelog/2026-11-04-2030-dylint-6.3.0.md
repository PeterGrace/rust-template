# 2026-11-04 20:30 EST: Build dylint with cargo-dylint 6.3.0

## Summary

cargo-dylint 6.0.4's driver no longer builds: its build script fails with "`revparse_ext`
failed for `master`". A project generated from this template (cargo-testcache) hit this on its
first GitHub CI run. Generated projects now install 6.3.0, which builds and loads the lint
library tags the template already pins.

## Changed

- `.github/workflows/ci.yml`: the dylint job installs `cargo-dylint@6.3.0` and
  `dylint-link@6.3.0`, and its comment says why.
- `.forgejo/workflows/ci.yml`: the same version for the fallback `cargo install`.
- `Cargo.toml`: the `[workspace.metadata.dylint]` comment says which driver CI uses, and to
  check `just dylint` before bumping a library tag.

## Tests

- Generated a project with `ci=github`, `hegel=true`, `dylint=true`: the workflow renders
  6.3.0, and `just gate` exits 0, with dylint loading both libraries.
- Generated a project with `ci=forgejo`: the install line renders 6.3.0.
- The same change, with these library tags, passed GitHub CI on cargo-testcache (PR #2).

## Not done

- The Forgejo job installs cargo-dylint only if the job image lacks it. If the shared CI
  runner image ships cargo-dylint 6.0.4, that image needs updating too.
