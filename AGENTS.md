# Agent instructions

Before changing any code in this repository, read and follow:

- [`.claude/CLAUDE.md`](.claude/CLAUDE.md)
- the files in [`.claude/rules/`](.claude/rules/) whose path globs match the files you
  are changing (see the globs listed in `.claude/CLAUDE.md`)

`.claude/` is the single source of truth for agent guidance. Keep this file a pointer;
do not copy that guidance here.
